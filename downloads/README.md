# 안드로이드 개발 APK

iPhone용은 [iOS 프로젝트 ZIP](https://github.com/MJY8647/JUNYOUNGWORK/raw/refs/heads/main/downloads/LUMI-iOS-source.zip)을 받아 Mac의 Xcode에서 열어야 합니다. 자세한 방법은 [iOS 설치 안내](../ios/README.md)를 확인하세요. 서명한 IPA 파일은 아직 제공하지 않습니다.

[LUMI-debug.apk 다운로드](https://github.com/MJY8647/JUNYOUNGWORK/raw/refs/heads/main/downloads/LUMI-debug.apk)

Android 10 이상용 개발 버전입니다. 구현된 기능은 무료이며, 메이투 전체 기능 완성본은 아닙니다. iPhone에는 설치할 수 없습니다.

무결성 체크섬은 [SHA256SUMS](SHA256SUMS)에 있습니다. 서명 키는 저장소에 포함하지 않습니다. 새 빌드에는 별도 개발 키가 생성될 수 있으므로 이전 APK와 서명이 다르면 업데이트 설치가 되지 않을 수 있습니다.
