# 폰파리 딜러 스튜디오

휴대폰 판매점 상담을 **탭만으로** 진행하는 도구입니다. 글은 최소화하고 숫자는 크게 보여줍니다.

- **견적** 10단계: 기종 → 용량 → 개통(통신사·가입유형) → 요금 → 6개월 후 변경 요금 → 지원(공시 vs 선약 자동 비교, 추가지원금) → 결제(할부·반납) → 혜택(부가·결합·카드) → 견적 → 개통 체크
- **시세표**: 통신사·가입·요금제·기종을 칩으로 고르면 카톡/밴드용 이미지(PNG)와 문구가 바로 만들어집니다
- **사후관리**: 개통일 하나로 요금제 변경 가능일(6개월·183일 중 늦은 날), 부가서비스 해지일, 약정 만료 알림을 만들고 휴대폰 캘린더(.ics)에 넣습니다

## 열기
`index.html`을 더블클릭하거나 `downloads/phoneparis-preview.html`(단일 파일)을 엽니다.

## 수정
모든 데이터는 `assets/content.js` 한 파일에 있습니다.
- 출고가: 2026-11-20 기준 확인값 (Apple 공식몰, 삼성 출고가 보도)
- **예시값(draft)**: 요금제, 공시지원금 공식, 부가서비스, 결합·카드 할인, 매장 이름·연락처 → 매장 단가표로 교체하세요
- 할부이자 연 5.9%, 선택약정 25%, 고가 요금제 유지 183일 (매장 계약 조건이 우선)
