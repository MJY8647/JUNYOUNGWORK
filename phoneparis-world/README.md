# 폰파리 — 에펠탑 광장 3D 소비자 사이트

원본 영상(phoneparis-designer-studio)의 장면 순서와 카메라 구도를 **실시간 3D(three.js)** 로 다시 만든 소비자용 사이트입니다.
영상 프레임을 넘기는 방식이 아니라, 탑·광장·군중·노점·여섯 폰팔이를 모두 코드로 만든 3D 장면입니다.

- 공유 페이지: https://claude.ai/artifact/YM1tRv2krYQ1ed5jjwkS3L (공유 메뉴에서 공개 범위 설정)
- 단일 파일 미리보기: `downloads/phoneparis-world-preview.html`

## 장면 (스크롤 한 번 = 한 장면)
| # | 영상 구간 | 카메라 | 화면 |
|---|---|---|---|
| 0 | 0:06 광장 전경 | 높은 사선 | 제목 |
| 1 | 0:08 탑 위 하강 | 탑 위에서 내려다봄 | 제목, 걷는 군중 |
| 2 | 0:11 아치 아래 | 지상, 아치 통과 | 제목 |
| 3–8 | 0:13–0:44 여섯 폰팔이 | 캐릭터 정면 | 말풍선 + 카드(탭 흐름) |
| 9 | 0:44 다시 광장 | 탑 올려다봄 | 마무리 제목 |

장면 사이 이동은 카메라 곡선 비행 + 속도에 따른 모션 블러(영상의 휙 전환). 캐릭터는 눈을 깜빡이고 마우스를 따라보며, 클릭하면 카드가 열립니다.

## 폰팔이별 클릭 흐름
- 디자이너: 칩 선택 → 상품 → 상세 → 상담 / 3D 폰꾸 작업실(기기·케이스·키링·뒷면, 360° 회전, 이미지 저장)
- 퀵퀵이: 4단계(탭하면 펼침) → 모델 선택 → 상담
- 자린고비: 싼 순 정렬, 0원만 필터 → 상세 → 상담
- 세이프티: 보호 조합 토글 + 5가지 약속(탭하면 펼침) → 상담
- 중고폰: S급/미개봉급 선택 → 상담
- 올인원: 모델 그리드 → 상세 → 상담

## 수정
문구·상품·가격·연락처는 `assets/content.js` 한 파일. 가격은 원본 영상 속 예시값입니다. 카카오톡 채널 링크는 TODO.

## 개발
- 무빌드: `index.html` 바로 열기 (three.js r128은 `assets/vendor/`에 포함, MIT)
- 테스트: `node phoneparis-world/test/world.test.js --shots phoneparis-world/screenshots`
- 공유 페이지 빌드: `python3 phoneparis-world/tools/build_artifact.py`
- WebGL이 없는 기기에서는 원본 영상의 장면 이미지(`assets/fallback/`)로 대체됩니다.
