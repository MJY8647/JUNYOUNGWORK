# 폰파리 — 에펠탑 광장 3D 소비자 사이트

원본 영상(phoneparis-designer-studio)의 장면 순서와 카메라 구도를 **실시간 3D(three.js)** 로 다시 만든 소비자용 사이트입니다.
영상 프레임을 넘기는 방식이 아니라, 탑·광장·군중·노점·여섯 폰팔이를 모두 코드로 만든 3D 장면입니다.

- 공유 페이지: https://claude.ai/artifact/YM1tRv2krYQ1ed5jjwkS3L (공유 메뉴에서 공개 범위 설정)
- 단일 파일 미리보기: `downloads/phoneparis-world-preview.html`

## 장면 (스크롤 한 번 = 한 장면)
| # | 영상 구간 | 카메라 | 화면 |
|---|---|---|---|
| 0 | 0:06 광장 전경 | 높은 사선 | 제목 |
| 1 | 0:08 탑 위 하강 | 탑 위에서 내려다봄 | 제목, 걷는 군중 |
| 2 | 0:11 아치 아래 | 지상, 아치 통과 | 제목 |
| 3–8 | 0:13–0:44 여섯 폰팔이 | 캐릭터 정면 | 말풍선 + 카드(탭 흐름) |
| 9 | 0:44 다시 광장 | 탑 올려다봄 | 마무리 제목 |

장면 사이 이동은 카메라 곡선 비행 + 속도에 따른 모션 블러(영상의 휙 전환). 캐릭터는 눈을 깜빡이고 마우스를 따라보며, 클릭하면 카드가 열립니다.

### 폰팔이마다 다른 호객
| 폰팔이 | 캐릭터 | 호객 동작 (3D) | 말투·말풍선 |
|---|---|---|---|
| 디자이너 | 폰꾸 스타일리스트 ★ | 팔을 펼쳐 소개, 몸 돌리기, 윙크 | 반짝이며 튀어나옴, 그라데이션 테두리 |
| 퀵퀵이 | 총알 배송 담당 !! | 두 번 점프, 빠른 손 흔들기, 바퀴 회전 | 흔들리며 밀려 들어옴, 대사도 가장 빠르게 |
| 자린고비 | 짠돌이 최저가 사냥꾼 ₩ | 몸 숙이고 가격표 흔들기, 곁눈질 | 귓속말처럼 흐릿하게, 점선 테두리 |
| 세이프티 | 든든한 케어 보안관 ✓ | 숨쉬기, 끄덕끄덕, 방패가 빛남 | 천천히 차분하게 |
| 중고폰 | 깐깐한 검수 장인 S | 표지판 들었다 놨다, 돋보기 눈 | 도장 찍듯 쾅 |
| 올인원 | 다 해 주는 해결사 ♪ | 몸 흔들기, 양팔 크게, 어깨 으쓱 | 느긋하게 흔들리며 |

문구(호객 3줄·마우스 올렸을 때 한마디·가게 대사)는 `assets/content.js`의 `dealers`에서 고칩니다.

### 마우스·터치 반응 (마우스가 있는 기기만, 동작 줄이기 설정 존중)
- 커서 링: 버튼 위에서 커지고, 3D 캐릭터 위에서는 폰팔이 색으로 바뀌며 「○○에게 사러 가기」 이름표
- 캐릭터 위에 올리면 깡충 + 빛나며 한마디, 말풍선 위 이모트가 동작에 맞춰 튀어나옴
- 카드: 마우스 방향으로 3D 기울기와 스포트라이트, 셀링포인트 줄이 밀려남, 버튼이 커서 쪽으로 끌려옴(자석)
- 하단 장면 도크: 가운데 유리 알약, 현재 장면 표시가 미끄러져 이동, 올리면 떠오름
- 가게: 폰 카드가 떠오르며 사진이 살짝 돌아감, 용량 상자 뚜껑 열림, 할인 카드 반사광, 할부 동전 회전, 누르면 물결

### 모바일
- 휴대폰·태블릿(가로로 돌린 폰 포함)은 가벼운 3D: 그림자 끔, 군중 1,300명, 해상도 상한 1.5배, 모션 블러 약하게
- 2초 평균이 30fps 아래면 해상도를 0.25배씩 자동으로 낮춤 (1배까지)
- 가게가 화면을 덮는 동안 3D 광장은 절반 속도로 그림 (배터리·발열)
- 넓은 면(카드·제목)은 유리 흐림 대신 불투명한 면
- 화면별 배치: 세로 폰은 아래에서 올라오는 카드·가게, 키 작은 폰(아이폰 SE)·좁은 폰(360px)은 간격·글자 축소, 가로로 돌린 폰은 장면 바를 위로 올리고 카드·가게를 화면 높이에 맞춤
- 캐릭터를 탭하면 깡충 반응하며 가게로 들어감 (터치에는 마우스 올리기가 없으므로)
- 아이폰 입력칸 확대 방지(16px), 홈 인디케이터·노치 여백, 손가락 크기의 누르는 면적

## 구매 흐름 (1mm STORE v6 판매 프로세스 적용)
카드의 「○○에게 사러 가기」를 누르면 그 폰팔이의 가게가 열립니다. 폰팔이가 대사창에서 말하고, 소비자는 말풍선 버튼과 테이블 위 물건(폰 진열, 용량 상자, 할인 카드, 할부 동전, 계약서 도장, 서명)을 눌러 넘어갑니다.

`📱 폰 → ★ 셀링포인트 → 💬 상담 → 🧾 견적 → ✍️ 계약 → 📦 배송 → 🎉 완료`

| 단계 | 내용 (v6와 같음) |
|---|---|
| 폰 | 진열대에서 폰 → 색상 칩 → 용량 상자 |
| 상담 | 지금 통신사 → 가족·인터넷 결합 유지/최저가 → 한 달 데이터 |
| 견적 | 3사 + 자급제 방법을 월 납부 싼 순으로 → 공시지원금 vs 선택약정 25% 카드 → 할부 동전(일시불·12·24·36) → 계산서 |
| 계약 | 1mm 멤버십 3만 원 할인 → 항목 도장 + 손가락 서명 |
| 배송 | 퀵/택배/방문 수령 → 받는 분 → 주문 내역 확인 → 결제 |
| 완료 | 영수증 |

### 폰팔이마다 다른 ★ 셀링포인트 (소비자가 직접 결정)
| 폰팔이 | 결정하는 것 | 흐름에 미치는 영향 |
|---|---|---|
| 디자이너 | 케이스·키링·뒷면 (3D로 돌려 보기) | 계산서·영수증에 폰꾸 세트 |
| 퀵퀵이 | 받는 속도(오늘 퀵/방문/택배) · 개통 시점 | 배송 단계 자동 선택, 방문이면 주소 생략 |
| 자린고비 | 우선순위(매달 최저/오늘 0원/2년 총액) | 견적 정렬 기준 |
| 세이프티 | 보호 3종(케이스·필름·보험) · 약속 도장 | 계산서에 보호 비용·월 보험료 |
| 중고폰 | 등급(S급/미개봉급) · 배터리 · 검수표 | 통신사 질문 없이 중고 견적 |
| 올인원 | 「알아서 해 줘」 | 상담 생략, 최저 조건 자동 선택 |

## 수정
문구·상품·가격·요금제·지원금·연락처는 `assets/content.js` 한 파일(`shop` 항목이 구매 흐름 숫자). 요금제·공시지원금·멤버십 할인은 예시값입니다. 결제는 실제로 되지 않는 프로토타입입니다.

## 개발
- 무빌드: `index.html` 바로 열기 (three.js r128은 `assets/vendor/`에 포함, MIT)
- 테스트: `node phoneparis-world/test/world.test.js --shots phoneparis-world/screenshots`
- 공유 페이지 빌드: `python3 phoneparis-world/tools/build_artifact.py`
- WebGL이 없는 기기에서는 원본 영상의 장면 이미지(`assets/fallback/`)로 대체됩니다.
