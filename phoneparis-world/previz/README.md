# 폰파리 3D 프리비즈

사이트(`assets/world.js`)의 3D 장면을 그대로 내보낸 파일입니다. 노점은 여섯 폰팔이만 있습니다.

| 파일 | 내용 |
|---|---|
| `phoneparis-previz.glb` | 장면 전체(탑·센강·강 건너·잔디·여섯 폰팔이와 노점·사람 975명). 하늘 구는 뺐음. 사람은 한 순간에 멈춘 상태 |
| ↳ 카메라 10개 | `shot_00_square` ~ `shot_09_finish` (사이트 스크롤 장면 순서, 16:9 기준 세로 화각) |
| `camera-shots.json` | 장면 10개의 카메라 위치·바라보는 점·세로 화각(도) |
| `camera-path-24fps.json` | 장면 사이 이동 경로를 24fps로 (구간마다 144프레임 = 6초). 위치, 회전(쿼터니언 xyzw), 화각 |
| `videos/` | 사이트 3D로 렌더한 프리비즈 영상. 16:9 광장 반복 / 광장→하강 이동 / 하강 반복, 9:16 광장→하강 이동 |
| `frames/` | 광장·하강 장면 첫 프레임 (16:9, 9:16) |

- 단위: 1 = 약 3.6m (탑 높이 92 ≈ 330m), 위쪽 = +Y. 블렌더에서 glTF로 가져오면 Z-up으로 자동 변환됩니다.
- 세로(9:16) 화면에서 사이트는 화각을 1.32배 넓힙니다(최대 80도).
- 다시 만들기: `node tools/export_previz.js previz` (사이트 3D가 바뀌면 이걸로 새로 뽑기), 영상은 `tools/render_previz.js`.
