# book-site — 『너무 성실한 시스템』 (이산)

bunqlabs.com에서 역설계한 사이트 구조(`studio-site/`)에 이산 작가의 책 『너무 성실한 시스템: 괴로움의 구조와 출구에 관하여 — 생존-안전 시스템 이론』의 내용을 적용한 원페이지 사이트입니다.

```bash
python3 -m http.server -d book-site 8080   # http://localhost:8080
node book-site/test/site.test.js           # 동작 테스트 10개
```

## 섹션 구성 (원본 구조 → 책 내용)

| 원본 사이트 섹션 | 이 사이트 |
|---|---|
| 첫 화면: 산 위의 작업 표지 + 큰 헤드라인 | 산 위의 **책 표지** + "괴로움은 고장이 아니다 ✦ 너무 성실한 정상 작동이다" |
| 손글씨·펜 표시가 그려지는 선언문 | 책이 약속하는 **세 문장** (결함 아님 · 구조로 이해 · 출구가 있다) |
| 고객사 로고가 바뀌는 로고 월 | 책의 **핵심 개념**이 차례로 바뀜 (위협 판정, 안전 규칙, 각성, 감정, 안전행동, 루프, 저항, 집착, 정체성의 결박, 운영권) |

| 메뉴 오버레이 | 페이지 · 4부 구성 · 철학 프로그램 카드 · 문의 · 테마 |
| 문의 폼 | 프로그램 참여 · 강연/북토크 · 기타 문의 |

## 콘텐츠 출처와 확인 필요 사항

- 서지 정보, 목차, 저자 소개, 출판사 소개, 발췌문은 **예스24 도서 상세 페이지**(2026-11-14 확인)에서 가져왔습니다.
  정가 20,000원 / 예스24 판매가 18,000원, 244쪽, A5, 2026-07-15 출간, ISBN 9791199286917 (전자책 9791199286924, 2026-07-24).
- 장 카드의 한 줄 소개 중 2장·14장 외에는 **장 제목과 출판사 소개를 바탕으로 쓴 초안**입니다 (`content.js`에 `draft: true`). 저자 확인 후 교체하세요.
- 발췌문은 쪽수와 함께 짧게만 실었습니다. 저자·출판사의 사용 동의를 받아 두세요.
- `hello@example.com`, SNS 링크(`#`)는 자리표시자입니다.
- 철학 프로그램은 자리만 만들어 두었습니다. 내용이 정해지면 `content.js`의 `program`과 포털 카드에 넣으면 됩니다.

## 수정 방법

모든 문구와 데이터는 `assets/content.js` 한 파일에 있습니다. 색은 `assets/styles.css` 맨 위 토큰, 책 표지 모양은 같은 파일 끝의 "book-specific" 부분입니다.
