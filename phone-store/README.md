# 작은폰가게 — 작은 행성 위의 휴대폰 쇼핑 마을 (프로토타입)

캐릭터를 움직여 작은 행성 마을을 돌아다니다가 가게에 들어가 폰을 고르는 판매 사이트입니다.
Messenger(messenger.abeto.co)를 분석해 얻은 플레이 구조와 기법을 적용했습니다.
적용한 것은 구형 맵, 자유 시점 카메라, 3인칭 이동, 따라오는 카메라, NPC 말풍선, 구역 이름 표시, 근접 상호작용, 툰 셰이딩, 가려진 캐릭터 실루엣입니다.
지형, 건물, 캐릭터는 새로 만들었고 그 게임의 에셋은 쓰지 않았습니다.

## 실행

```bash
cd phone-store
npm install
npm run dev      # 개발 서버
npm test         # 가격 계산 테스트
npm run build    # dist/ 에 정적 파일 생성 (어느 경로에 올려도 동작)
```

## 구성

| 화면 | 동작 |
|---|---|
| 홈 `#/` | 작은 행성 마을. 드래그로 시점 회전, 휠·핀치로 확대, WASD·방향키 또는 땅을 탭해서 이동, Space(모바일은 버튼)로 점프. 북극 광장 → 순환 도로(횡단보도·신호등·차·버스정류장·무지개 육교) → 가게 5곳(SAMSUNG·Apple 영업 중, 나머지 3곳은 COMING SOON) → 남반구 숲·연못·통신탑 언덕. 바로가기를 누르면 보행로와 횡단보도를 따라 가게까지 걸어감. 가게 앞에서 "들어가기"(E 키)로 진열장이 열림. SAMSUNG은 폴드·플립·울트라·일반, Apple은 듀오·프로·일반·SE·Air 시리즈를 먼저 고르고, 고른 시리즈의 모델이 최신순(출시 예정 → 최근 출시)으로 나옴 |
| 목록 `#/products` | 제조사·실속폰 탭, 신상품/인기/가격순 정렬, 출시 예정 |
| 상세 `#/products/:id` | KT초이스 상세 구성: 색상·용량·가입유형·할인방법(총 할인액 비교)·요금제(추천 3개 + "다른 요금제 선택" 팝업: 무제한+혜택 고르기 / 무제한 실속 / 넉넉한 데이터 / 가볍게 쓰기)·요금제 특별혜택(택1)·할부(일시납~36개월)·배송(택배/당일 퀵/방문수령)·기본 사은품·제휴카드 할인·추가 상담 체크 → 최종 주문서(지원금·할부원금·할부이자·요금할인·카드할인·월 예상 금액) → 상세정보·구매후기·유의사항 탭, 최근 본 상품. 3D 폰 회전·색상 변경 |
| 장바구니 `#/cart` | 담기·삭제·합계, 줄마다 "주문하기"(휴대폰은 회선별로 한 대씩 주문). 이 브라우저에만 저장 |
| 구매 시작 `#/buy` | 상세 "바로 구매" 또는 장바구니 "주문하기"에서 진입. 로그인 회원은 바로 주문서로, 아니면 **회원(카카오·네이버·Google 3초 가입)** 또는 **비회원** 선택 |
| 3초 가입 `#/login` → `#/signup` | 소셜 계정 확인 → 필수 약관(만 14세 이상, 이용약관, 개인정보) + 선택 마케팅 동의 → 가입 완료 |
| 주문서 `#/order` | ① 상품 확인 ② 명의자 본인인증(이름·생년월일·현재 통신사·휴대폰 인증번호, 미성년자 법정대리인 안내, 신규·번호이동은 2026-07-06 시행 강화 본인확인 방법 선택) ③ 배송(회원은 기본 배송지 저장) ④ 약관 동의 ⑤ 결제(할부는 0원, 일시납은 결제수단) |
| 신청 완료 `#/order/done` | 주문번호(복사), 진행 단계(접수 → 공식신청서 → 본인확인·개통 → 배송), 다음 할 일 |
| 주문 조회 `#/orders` | 회원은 내 주문 목록, 비회원은 이름·휴대폰·주문번호로 조회 |
| 마이페이지 `#/mypage` | 계정, 기본 배송지, 주문 내역, 로그아웃, 탈퇴 |

- `src/products.js` 상품 데이터
- `src/config.js` 매장 정보·요금제·정책
- `src/pricing.js` 가격 계산
- `src/audio.js` 효과음·배경음악 (Web Audio로 직접 합성, 음원 파일 없음. 첫 입력 후 재생, 마을 화면에서 음악·효과음 각각 끄기 가능)
- `src/purchase.js` 구매 흐름 화면, `src/account.js` 회원·소셜 로그인, `src/orders.js` 주문 저장·검증 규칙
- `src/three/planet.js` 행성 마을 (배치·이동·카메라·육교·차)
- `src/three/parts.js` 사람·가게 건물 모델
- `src/three/viewer.js` 상세 3D 뷰어

## 운영 전에 꼭 바꿔야 할 것

1. **지원금:** 실제 공통지원금·추가지원금 정책 데이터를 연결해야 합니다.
   - 지금은 "출고가 − 표시 할인가"를 기기값 할인 최대액으로 씁니다.
   - ZIP 안에서도 아이폰18 프로의 할인액이 화면마다 다릅니다(목록 600,000원, 상세 500,000원).
   - 상세 주문 요약에는 출고가 1,353,000원처럼 다른 값이 남아 있었습니다.
2. **요금제:** 5G 초이스 3종만 넣었습니다. 저가 요금제는 2026년 기준 공식 값을 확인한 뒤 추가하세요.
3. **이미지:** 상품 이미지는 분석 자료입니다. 제조사나 유통사에서 사용 허락을 받은 이미지로 교체하세요.
4. **매장 정보:** 매장명, 사업자 정보, 상담 번호를 `src/config.js`에 입력하세요.
5. **서버 기능:** 주문, 상담, 로그인, 결제(PG) 서버를 구현해야 합니다. 서버에서 최종 견적을 다시 계산해야 합니다.
6. **소셜 로그인:** 각 개발자센터에서 앱 키를 받아 `src/config.js`의 `SOCIAL`에 `clientId`와 `redirectUri`를 넣으면 실제 로그인 창으로 연결됩니다. 돌아온 인가 코드를 토큰으로 바꾸는 서버(client secret 보관)가 필요합니다. 키가 없으면 데모 계정으로 동작합니다.
7. **본인인증·결제:** 휴대폰 인증(PASS 등 본인확인기관), 결제 대행(PG), 통신사 공식신청서 연동이 필요합니다. 지금은 인증번호를 화면에 보여 주는 데모이고, 결제·접수는 되지 않습니다. 주문은 이 브라우저 localStorage에만 저장됩니다.
8. **지원금표 (`src/subsidies.js`):** KT 다이렉트샵 공시지원금 표는 reCAPTCHA로 보호돼 자동으로 가져올 수 없어요. 판매점이 받은 최신 공시(공통)지원금을 요금제·가입유형별로, 판매점 추가지원금을 가입유형별로 입력하면 화면에 "공시지원금 / 판매점 추가지원금"이 나뉘어 계산돼요. 2025-07-22 단통법 폐지로 추가지원금 상한(공시의 15%)이 없어졌고, 선택약정(요금할인 25%) 가입자도 추가지원금을 받을 수 있게 계산해요. 표가 없는 상품은 수집 당시 할인액을 '예상 지원금'으로 보여줘요.
9. **용량별 출고가:** 아이폰18 프로맥스·아이폰 듀오·아이폰17 NEW의 추가 용량은 애플 공식몰(2026-11-23) 용량별 가격 차이로 계산한 예상가예요("(예상)" 표시). 나머지 상품의 추가 용량은 KT 출고가가 없어 "상담 후 안내"로 막혀 있어요. KT 출고가를 받으면 `src/products.js`의 `storagePrices`에 넣어 주세요.
10. **주소 검색:** 카카오(다음) 우편번호 서비스를 써요(무료, 키 불필요). 도로명 주소만 입력하고 검색하면 주소와 우편번호가 자동으로 들어가요. 서비스를 불러오지 못하면 직접 입력으로 바뀌어요. 카카오 공지에 따라 스크립트 주소는 `t1.kakaocdn.net`(기존 `t1.daumcdn.net`은 2026-11-30 종료)을 써요.
