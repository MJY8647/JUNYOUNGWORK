# 작은폰가게 — 작은 행성 위의 휴대폰 쇼핑 마을 (프로토타입)

캐릭터를 움직여 작은 행성 마을을 돌아다니다가 가게에 들어가 폰을 고르는 판매 사이트입니다.
Messenger(messenger.abeto.co)를 분석해 얻은 플레이 구조와 기법을 적용했습니다.
적용한 것은 구형 맵, 자유 시점 카메라, 3인칭 이동, 따라오는 카메라, NPC 말풍선, 구역 이름 표시, 근접 상호작용, 툰 셰이딩, 가려진 캐릭터 실루엣입니다.
지형, 건물, 캐릭터는 새로 만들었고 그 게임의 에셋은 쓰지 않았습니다.

## 실행

```bash
cd phone-store
npm install
npm run dev      # 개발 서버
npm test         # 가격 계산 테스트
npm run build    # dist/ 에 정적 파일 생성 (어느 경로에 올려도 동작)
```

## 구성

| 화면 | 동작 |
|---|---|
| 홈 `#/` | 작은 행성 마을. 드래그로 시점 회전, 휠·핀치로 확대, WASD·방향키 또는 땅을 탭해서 이동, Space(모바일은 버튼)로 점프. 북극 광장 → 순환 도로(횡단보도·신호등·차·버스정류장·무지개 육교) → 가게 5곳(삼성 코너·애플 코너·실속폰 마켓·요금제 센터·신상 쇼룸) → 남반구 숲·연못·통신탑 언덕. 바로가기를 누르면 보행로와 횡단보도를 따라 가게까지 걸어감. 가게 앞에서 "들어가기"(E 키)로 진열장이 열림 |
| 목록 `#/products` | 제조사·실속폰 탭, 신상품/인기/가격순 정렬, 출시 예정 |
| 상세 `#/products/:id` | 3D 폰을 드래그해 회전, 색상 선택 시 3D 색 변경. 용량·가입유형·할인방법·요금제·할부 선택에 따라 월 예상 금액 계산 |
| 장바구니 `#/cart` | 담기·삭제·합계. 이 브라우저에만 저장 |
| 주문서·로그인 | 화면만 있음. 입력 내용은 전송·저장되지 않고 접수되지 않았다고 안내 |

- `src/products.js` 상품 데이터
- `src/config.js` 매장 정보·요금제·정책
- `src/pricing.js` 가격 계산
- `src/three/planet.js` 행성 마을 (배치·이동·카메라·육교·차)
- `src/three/parts.js` 사람·가게 건물 모델
- `src/three/viewer.js` 상세 3D 뷰어

## 데이터 출처와 신뢰도

| 항목 | 출처 | 상태 |
|---|---|---|
| 상품 30종 이름·출고가·할인가·이미지·출시일·품절 | 사용자 제공 ZIP (2026-11-19 수집 표시값) | 판매처 표시값. 애플 공식몰 가격과 1만 원 이내로 일치(아이폰18 프로 1,990,000 / 1,991,000원 등) |
| 요금제 3종 (130,000 / 110,000 / 90,000원) | KT 공식 5G 초이스 상품 페이지 (2026-05-29 게시본) | 확인됨 |
| 할부수수료 연 5.9%, 계산식 | ZIP 상세 페이지 | 원본 예시(772,000원·24개월 → 34,180원)와 일치하도록 테스트 |
| 아이폰18 프로 용량별 가격·색상 4종 | ZIP 상세 페이지 | 이 상품만 있음 |
| 다른 상품의 색상, 추가 용량 가격 | 없음 | "대표 색상", "가격 문의"로 표시 |
| 3D 폰 색(tone) | 상품 이미지에서 자동 추출 | 표시용 |

## 운영 전에 꼭 바꿔야 할 것

1. **지원금:** 실제 공통지원금·추가지원금 정책 데이터를 연결해야 합니다.
   - 지금은 "출고가 − 표시 할인가"를 기기값 할인 최대액으로 씁니다.
   - ZIP 안에서도 아이폰18 프로의 할인액이 화면마다 다릅니다(목록 600,000원, 상세 500,000원).
   - 상세 주문 요약에는 출고가 1,353,000원처럼 다른 값이 남아 있었습니다.
2. **요금제:** 5G 초이스 3종만 넣었습니다. 저가 요금제는 2026년 기준 공식 값을 확인한 뒤 추가하세요.
3. **이미지:** 상품 이미지는 분석 자료입니다. 제조사나 유통사에서 사용 허락을 받은 이미지로 교체하세요.
4. **매장 정보:** 매장명, 사업자 정보, 상담 번호를 `src/config.js`에 입력하세요.
5. **서버 기능:** 주문, 상담, 로그인, 결제(PG) 서버를 구현해야 합니다. 서버에서 최종 견적을 다시 계산해야 합니다.
